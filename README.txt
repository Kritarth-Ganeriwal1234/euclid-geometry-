EUCLID'S GEOMETRY — AXIOMS & POSTULATES

Files:
- index.html: the complete interactive website. It works offline in a browser.

How to use:
1. Double-click index.html to open it in Chrome, Edge, or another browser.
2. Click the five postulate tabs and try the quiz.
3. To make a QR code that works for your teacher, the site must be hosted online first. Upload index.html to a static website host (for example GitHub Pages) and make the QR code point to the published web address. A QR code pointing to a local file on your computer will not work on someone else's phone.

Content is limited to the seven axioms (common notions), five postulates, diagrams, examples, and a short revision quiz.
