Part I · Common notions

The 7 Axioms

An axiom is a basic statement accepted as true without proof. Euclid’s axioms apply broadly to mathematical quantities and relationships.

1

Equal to the same thing

Things which are equal to the same thing are equal to one another.

If two quantities each equal 5, they must equal each other.

Example: If A = C and B = C, then A = B.
2

Adding equals

If equals are added to equals, the wholes are equal.

Adding the same amount to equal amounts keeps them equal.

Example: If A = B, then A + C = B + C.
3

Subtracting equals

If equals are subtracted from equals, the remainders are equal.

Taking away the same amount from equal amounts leaves equal remainders.

Example: If A = B, then A − C = B − C.
4

Things that coincide

Things which coincide with one another are equal to one another.

If two shapes fit exactly on top of each other, they are equal in size and shape.

Example: Two line segments that match exactly have the same length.
5

Whole and part

The whole is greater than the part.

A complete length is longer than one of its smaller parts.

Example: A 10 cm segment is longer than a 4 cm part of it.
6

Doubles of equals

Things which are double of the same things are equal to one another.

If two quantities are each twice the same quantity, they are equal.

Example: If A = C and B = C, then 2A = 2B.
7

Halves of equals

Things which are halves of the same things are equal to one another.

If two quantities are each half of the same quantity, they are equal.

Example: Half of 12 is 6; both halves of equal 12-unit quantities are 6.
Part II · Geometric assumptions

The 5 Postulates

A postulate is a basic assumption used specifically in geometry. Select a postulate to focus on its meaning and diagram.

Postulate 1

A straight line may be drawn from any one point to any other point.

Any two distinct points can be joined by a straight line segment.

Remember: Two points determine a straight line.
Exam tip: Axioms are general truths; postulates are assumptions about geometry. Learn the statements accurately, then use the examples to understand them.
